# JALYN — Style Meets Comfort

Premium women's fashion e-commerce storefront (homepage).

## Stack

- React 19 + Vite
- Tailwind CSS + Bootstrap 5.3 (grid/utilities)
- Framer Motion, Lenis, Swiper
- Zustand, TanStack Query, React Router
- Radix UI, Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

| Command        | Description              |
|----------------|--------------------------|
| `npm run dev`  | Start development server |
| `npm run build`| Production build         |
| `npm run preview` | Preview production build |
